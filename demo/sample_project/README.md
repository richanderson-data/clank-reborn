# Beacon (sample project)

A tiny fictional project that ships with Clank-Reborn so the demo has
something real to inspect. It contains one deliberate bug.

- `src/calc.py` - arithmetic helpers (one function is wrong on purpose)
- `src/report.py` - formats a one-line report
- `notes.txt` - project notes used by the demo prompts
- `data/measurements.csv` - a few rows for the search_text demo

This directory is intentionally small and safe to read.
